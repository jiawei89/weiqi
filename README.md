# 网页版围棋

一款专为平板设备优化的网页版围棋游戏，支持人机对战和两人对战，具备完整的积分系统和排行榜功能。

## 🎮 功能特性

### 核心功能
- **双游戏模式**：支持人机对战和两人面对面对战
- **灵活设置**：可自定义胜利条件（10/20/50分或自定义分数）
- **玩家管理**：支持自定义玩家姓名
- **本地积分**：完整的积分系统和排行榜
- **智能AI**：三种难度级别的AI对手

### 用户体验
- **响应式设计**：完美适配各种平板设备
- **触摸优化**：专为触摸设备优化的交互
- **流畅动画**：优雅的过渡和动画效果
- **本地存储**：所有数据保存在本地，保护隐私

## 🚀 快速开始

### 直接使用
1. 克隆或下载项目文件
2. 用浏览器打开 `index.html` 文件
3. 即可开始游戏！

### 本地服务器运行
```bash
# 使用Python启动简单HTTP服务器
python -m http.server 8000

# 或使用Node.js的http-server
npx http-server
```

然后在浏览器中访问 `http://localhost:8000`

## 🎯 游戏规则

### 基本规则
- 采用19×19标准棋盘
- 黑白双方交替下子
- 遵循标准围棋规则（禁止自杀、劫争处理等）
- 支持提子和领地计算

### 获胜条件
- 达到预设的目标分数（10/20/50分或自定义）
- 双方连续pass后计算最终得分
- 白方贴6.5目

### 积分系统
- 胜利获得基础积分
- AI难度越高，积分越多
- 失败扣除少量积分
- 连胜有额外奖励

## 🎮 操作指南

### 游戏控制
- **下棋**：点击棋盘交叉点放置棋子
- **悔棋**：撤销最近的操作（人机模式撤销两步）
- **弃子**：放弃当前回合
- **认输**：直接结束游戏并判定失败
- **暂停**：打开游戏菜单

### 设置选项
- **音效开关**：启用/禁用游戏音效
- **振动反馈**：启用/禁用触摸振动
- **显示坐标**：显示/隐藏棋盘坐标
- **动画效果**：启用/禁用动画

## 🏆 排行榜系统

### 排行规则
- 默认按总积分排序
- 支持按胜率、连胜等排序
- 显示前20名玩家
- 实时更新排名

### 数据管理
- 所有数据存储在浏览器本地
- 支持清空所有历史数据
- 隐私安全，不上传任何信息

## 🔧 自定义配置

### 修改AI难度
在 `script.js` 中的 `GoAI` 类可以调整AI算法参数：

```javascript
getMaxDepth() {
    switch (this.difficulty) {
        case 'easy': return 1;    // 初级
        case 'medium': return 2;  // 中级
        case 'hard': return 3;    // 高级
        default: return 2;
    }
}
```

### 修改积分规则
在 `script.js` 中的 `calculateScoreChange` 方法可以调整积分计算：

```javascript
calculateScoreChange(isWin, result) {
    let baseScore = 10;  // 基础积分
    if (isWin) {
        // 根据难度调整积分
        // ...
    }
    return baseScore;
}
```

## 🐛 问题排查

### 常见问题

**Q: 棋盘显示不完整或比例不对**
A: 检查浏览器缩放设置，推荐100%缩放

**Q: 触摸操作不灵敏**
A: 确保使用支持的浏览器版本，清理触摸屏

**Q: AI响应慢**
A: 在设置中将AI难度调低，或检查设备性能

**Q: 排行榜数据丢失**
A: 检查浏览器是否清除了本地存储数据

### 性能优化
- 推荐在Chrome或Safari浏览器中运行
- 关闭不必要的浏览器标签页
- 确保设备有足够的内存空间
